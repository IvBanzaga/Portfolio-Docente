## 1. Objetivo de este documento

Este archivo reúne los proyectos publicados en el portfolio actual y
cinco aplicaciones añadidas posteriormente. Está pensado como documento
de referencia para diseñar y desarrollar un nuevo portfolio profesional.

Incluye enlaces de acceso, fichas descriptivas, funcionalidades
conocidas, tecnologías identificadas y observaciones para completar la
documentación.

**Criterio de fiabilidad:** se distingue entre información visible en
las páginas y datos que todavía deben confirmarse. No se atribuyen
tecnologías o funcionalidades que no estén documentadas. Algunas
aplicaciones son SPA y su contenido no se ha podido extraer por
completo; en esos casos se indica expresamente.

## 1. Urban Manager

-   **Tipo:** aplicación web de gestión de incidencias urbanas.
-   **Demo / producción:** https://urbanmanager.creamiproyecto.com/

    problemas de su ciudad ---por ejemplo, residuos, alumbrado o
    calzadas--- y para que los administradores gestionen los avisos.

        incidencias.

-   **Tecnologías documentadas:** PHP 8.x, JavaScript, Tailwind CSS,
    MySQL, Supabase, Google OAuth, Leaflet, OpenStreetMap, Nominatim,
    Node.js, Apache, Git y Capacitor.

    roles, operaciones CRUD, carga de imágenes, mapas, geolocalización,
    panel administrativo e integración de servicios externos.
